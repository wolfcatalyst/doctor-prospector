# Contributing

Doctor Prospector is provided as-is and **isn't actively maintained**. Pull requests aren't reviewed, and there's no issue tracker.

**Want to change something?** Fork it and make it yours. The license lets you modify it, use it in your business and share your changes (see [LICENSE](LICENSE)). The docs are written so you, or your AI coding assistant, can work on it without the author:

- [README](README.md): install options and configuration
- [docs/DATA_REFRESH_RUNBOOK.md](docs/DATA_REFRESH_RUNBOOK.md): keeping the data current, and fixing it when a source changes
- [CLAUDE.md](CLAUDE.md) and [PDR.md](PDR.md): architecture and conventions

**Want it built for you?** Paid work is available, for new features, fixes, or a license that fits a use the standard terms don't allow (such as offering it as a hosted service). Reach out through [github.com/wolfcatalyst](https://github.com/wolfcatalyst).
